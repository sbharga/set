How to play

Every card has four features. In a valid set of three cards, each feature must be all the same or all different across the three cards — never two matching and one different.

Shape
oval, diamond, squiggle
Color
red, green, purple
Number
one, two, three
Shading
solid, striped, open
✓ Valid set

Same shape, same color, every number different, every shading different.

✗ Not a set

Two cards are red and one is green — color is neither all same nor all different.

Playing versus

  • The board is shared. Everyone searches at once — there are no turns.
  • See a set? Press SET! The board locks to you alone for 10 seconds.
  • Tap three cards. The third tap submits automatically.
  • Correct → +1 point, the cards vanish and are replaced.
  • Wrong, or time runs out → −1 point and a 5 second cooldown before you can buzz again.
  • Think there's no set on the board at all? Press No Set. Right → +1 point and three more cards are dealt. Wrong → same penalty as a bad set.
  • The match ends when the deck runs out and no set remains on the board. Most sets wins.

Shortcuts

  • space — SET! (buzz)
  • N — No Set
  • M — mute / unmute sound
