How to play SET

Find three cards. For every feature, the cards must be either all the same or all different. Never two-and-one.

Shape
oval, diamond, squiggle
Color
three colors
Number
one, two, three
Fill
solid, striped, open
✓ This is a SET

Shape and color are the same. Number and fill are all different.

✗ Not a SET

Two are one color and one is another, so color breaks the rule.

Play with friends

  1. Everyone searches the shared cards at the same time.
  2. See a set? Choose I found a SET! You’ll have 10 seconds to pick your three cards.
  3. Your third card checks the set automatically. A correct set earns 1 point.
  4. A wrong set or timeout costs 1 point, then you rest for 5 seconds.
  5. Can’t find any set? Choose No SET here. If everyone agrees and the group is right, three cards are added. A wrong vote costs 1 point.
  6. When the deck is empty and no sets remain, the player with the most points wins.
