The game

SET is a card game invented by Marsha Falco in 1974. SET® is a registered trademark of Set Enterprises, Inc., and the physical game is published by PlayMonster. This website is an unofficial, independent fan project. It is not affiliated with, sponsored by, or endorsed by Set Enterprises or PlayMonster. If you enjoy it, please support the creators by buying the real game.

This version

Built and run by Shreyas. The source code is on GitHub and is released under the CC0 1.0 public domain dedication. Card artwork is drawn by the app as SVG, sounds are synthesized in your browser with the Web Audio API, and text uses your device's system fonts.
